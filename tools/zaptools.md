# ZAPTOOLS
*117+ free browser-based developer tools — no signup required*

**Website:** [https://zaptools.web.app](https://zaptools.web.app)

## Introduction
ZapTools is a collection of 117+ free browser-based developer utilities. All tools run entirely in the browser, require no signup, and cover a wide range of everyday development tasks from data formatting to encoding and debugging.

## Data Formatting Tools

### JSON Formatter
Paste raw JSON and instantly pretty-print, minify, or validate it.

### SQL Formatter
Format and beautify raw SQL queries for better readability.

### Markdown Preview
Write Markdown on the left, see a live-rendered preview on the right.

### Diff Tool
Compare two blocks of text side-by-side and highlight the differences.

## Encoding & Decoding Tools

### Base64 Encoder / Decoder
Encode text or files to Base64, or decode Base64 strings back to their original content.

### URL Encoder / Decoder
Encode special characters for use in URLs, or decode percent-encoded strings.

### JWT Decoder
Paste a JSON Web Token to inspect its header, payload, and signature without sending it to a server.

### HTML Entity Encoder / Decoder
Convert special characters to their HTML entity equivalents and back.

## Security & Hashing Tools

### Hash Generator
Generate MD5, SHA-1, SHA-256, and SHA-512 hashes from any input string.

### UUID Generator
Create random UUIDs (v4) for use as unique identifiers in databases, APIs, or configs.

### Password Generator
Generate strong, random passwords with configurable length and character sets.

## Regex & Parsing Tools

### Regex Tester
Write a regular expression, supply test strings, and see matches highlighted in real time.

### Cron Expression Builder
Build and validate cron expressions with a human-readable description of the schedule.

### JSON Path Evaluator
Query JSON data using JSONPath expressions and see matching results instantly.

## Conversion Tools

### Color Converter
Convert colors between HEX, RGB, HSL, and other formats with a visual preview.

### Number Base Converter
Convert numbers between binary, octal, decimal, and hexadecimal.

### Timestamp Converter
Convert between Unix timestamps and human-readable date/time formats.

### Unit Converter
Convert between common units of length, weight, temperature, and more.

## Text Utilities

### Text Case Converter
Convert text between camelCase, snake_case, PascalCase, UPPER_CASE, and more.

### Lorem Ipsum Generator
Generate placeholder text in paragraphs, sentences, or words.

### String Length & Word Counter
Count characters, words, sentences, and lines in any text input.

### Text Diff / Compare
Highlight differences between two text inputs at the character or line level.

## Tips
- All tools run client-side in the browser — your data never leaves your machine.
- No account or signup is required.
- Tools are accessible on desktop and mobile browsers.
- Bookmark individual tool pages for quick access.
